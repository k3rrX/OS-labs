# Лабораторная работа №4: Динамические библиотеки

## Задание
Реализация математических библиотек и их использование двумя способами.

## Библиотеки
1. **libmath_integral.so** - вычисление интеграла sin(x)
   - Метод прямоугольников
   - Метод трапеций
   
2. **libmath_geometry.so** - вычисление площади фигур
   - Прямоугольник
   - Прямоугольный треугольник

## Программы
- **program1** - использование библиотек на этапе компиляции (compile-time linking)
- **program2** - динамическая загрузка библиотек во время выполнения (runtime linking)

## Сборка
```bash
make all

Запуск

# Программа 1 (compile-time linking)
./program1

# Программа 2 (runtime linking)
LD_LIBRARY_PATH=./build ./program2

# Или тестируем всё
make test
